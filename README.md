# 🍬 Mithai Corner - Indian Sweet Shop Landing Page

A beautiful and responsive e-commerce landing page for an Indian sweet shop built with HTML, CSS, and JavaScript.

## 🌟 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Product Showcase**: 12 authentic Indian sweets with images and descriptions
- **Category Filtering**: Filter sweets by Traditional, Festival Special, and Modern categories
- **Search Functionality**: Search for specific sweets by name or description
- **Contact Form**: Users can express interest and send messages about products
- **Interactive Elements**: Hover effects, smooth animations, and modern UI
- **Real Images**: Uses placeholder images from Picsum Photos service

## 🍯 Products Included

### Traditional Sweets
- Gulab Jamun - Soft, spongy milk dumplings in rose syrup
- Rasgulla - Spongy cottage cheese balls in light syrup
- Kaju Katli - Diamond-shaped cashew fudge with silver leaf
- Ladoo - Round sweet balls made with gram flour
- Barfi - Dense milk-based sweet with nuts
- Jalebi - Crispy, spiral-shaped sweet in syrup

### Festival Special
- Diwali Special Mix - Assorted sweets for Diwali
- Holi Gujiya - Sweet dumplings for Holi
- Raksha Bandhan Thali - Special thali for siblings

### Modern Sweets
- Chocolate Barfi - Traditional barfi with chocolate
- Fusion Ladoo - Modern twist on traditional ladoo
- Sugar-Free Sweets - Healthy alternatives

## 🚀 How to Use

1. **Open the Website**: Simply open `index.html` in your web browser
2. **Browse Products**: Scroll down to see all available sweets
3. **Filter by Category**: Use the filter buttons to view specific categories
4. **Search**: Use the search bar to find specific sweets
5. **Show Interest**: Click "Interested" on any product to go to the contact form
6. **Contact**: Fill out the contact form to send your requirements
